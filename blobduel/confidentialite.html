Confidentialité

Dernière mise à jour : 11 octobre 2026. S'applique au jeu BLOB DUEL (version de test 0.8.0) et à cette page.

En bref

BLOB DUEL ne crée aucun compte, n'affiche aucune publicité, n'envoie aucune statistique et ne contacte aucun serveur. Cette page de téléchargement n'utilise ni cookie ni outil de mesure d'audience.

Sur ton ordinateur

Le jeu enregistre un seul fichier, settings.json, dans %APPDATA%\Godot\app_userdata\BLOB DUEL\. Il contient tes réglages (volumes, plein écran, secousses, glow, niveau de l'IA, dernière carte, port réseau) et, si l'option est activée, le dernier code d'invitation saisi. Ce fichier ne quitte jamais ton ordinateur. Le jeu n'écrit pas de journal.

Pour tout effacer : Paramètres → Données et confidentialité → Effacer mes données locales, ou supprime le dossier ci-dessus. Tu peux aussi désactiver Mémoriser le dernier code saisi.

En ligne

Les deux ordinateurs se connectent directement l'un à l'autre. Ton adresse IP est donc connue de ton adversaire, comme pour toute connexion directe ; le code d'invitation de l'hôte contient son adresse IP. Pendant la partie, seules des informations de jeu circulent (déplacements, visée, tirs, score) : aucun nom, aucun identifiant d'appareil. Ces données ne passent par aucun serveur et ne sont conservées ni par le jeu ni par l'éditeur. Elles sont chiffrées : une personne sur le même réseau ne peut pas les lire, et la clé secrète du salon n'est jamais transmise.

Partage ton code uniquement avec la personne avec qui tu veux jouer. Un réseau privé comme Tailscale évite d'exposer ton adresse IP publique.

Hébergement de cette page

Cette page et le fichier du jeu sont servis par le site tdinvasion.com, hébergé chez Railway. La page ne charge rien depuis un autre site : polices, images et styles sont hébergés ici. Aucun cookie, aucune mesure d'audience.

Pour limiter les abus (nombre de téléchargements, essais de code d'accès), le serveur compte les demandes avec une empreinte de ton adresse IP, calculée avec une clé aléatoire qui change chaque jour et reste en mémoire. Ton adresse elle-même n'est ni enregistrée ni écrite dans un journal, et ces compteurs disparaissent au bout de 24 heures au plus. L'hébergeur peut garder ses propres journaux techniques.

Tes droits

Aucune donnée personnelle n'est traitée pour le compte de l'éditeur. Pour toute question, écris sur le Discord. Tu peux aussi contacter la CNIL (cnil.fr).

Changements

Si une future version ajoute une collecte de données (classement en ligne, comptes…), cette page sera mise à jour avant.
